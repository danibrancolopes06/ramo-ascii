# Ramo ASCII

Ramos de flores dibujados con letras de colores, directamente en el navegador.

- **Lirios:** los tallos crecen, salen las hojas, se abren los lirios y aparecen las estrellas.
- **Jarrón:** un ramo de rosas que crece desde un jarrón, se mece y cambia de color.

Toca la pantalla o pulsa **Repetir** para verla otra vez.

Hecho con HTML, CSS y JavaScript, sin librerías. Pruebas del motor: `node --test tests/*.test.mjs`.
